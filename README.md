# ✊ Rock, Paper, Scissors

My first Rock, Paper, Scissors game built using Python as part of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

## 📌 About the Project

This is a simple command-line Rock, Paper, Scissors game where the player competes against the computer.

The player chooses between rock, paper and scissors, and the computer randomly selects its own choice. The program then compares both choices and announces the result.

ASCII art is used to display the three options in the terminal.

## 🛠️ Technologies Used

- **Python 3**
- `random` module – to generate the computer's random choice.
- ASCII art – to visually represent rock, paper and scissors in the terminal.

## 📚 What I Learnt

Through this project, I practised several fundamental Python concepts:

1. **Variables** – storing user choices and computer choices.
2. **User Input** – using `input()` to receive the player's selection.
3. **Data Type Conversion** – using `int()` to convert the input into an integer.
4. **Conditional Statements** – using `if`, `elif` and `else` logic to determine the winner.
5. **Importing Modules** – importing Python's built-in `random` module.
6. **Random Number Generation** – using `random.randint()` to generate the computer's choice.
7. **ASCII Art** – using multiline strings to display illustrations in the terminal.
8. **Comparison and Logical Operators** – comparing the player's and computer's choices to determine the outcome.

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository or download the Python file.
3. Open the project in your preferred code editor or terminal.
4. Run the following command:

```bash
python main.py
```

5. Enter your choice when prompted:
   - `0` for Rock
   - `1` for Paper
   - `2` for Scissors

6. The computer will generate its choice and display the result.
